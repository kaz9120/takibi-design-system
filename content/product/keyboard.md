マウスで触れることは、すべてキーボードでもできるようにします。Base UI のコンポーネントは下の決まりどおりに動きます。独自にコンポーネントを組むときも、同じ決まりに合わせます。

## 共通の決まり

| キー | 起きること |
|---|---|
| Tab / Shift + Tab | 次の / 前の操作できる場所へ移る |
| Enter | ボタンを押す。リンクを開く。一覧で選んでいる項目を実行する |
| Space | ボタンを押す。チェックボックスやスイッチを切り替える |
| Esc | 開いているもの（メニュー、ダイアログ、ポップオーバー）を閉じ、開いた要素にフォーカスを戻す |
| ↑ ↓ ← → | グループの中で項目を移る（タブ、ラジオ、メニュー、ツールバー） |
| Home / End | グループの最初の / 最後の項目へ移る |

## グループの中は矢印、グループの間は Tab

タブ、ラジオ、トグルのグループ、ツールバー、メニューは、Tab でグループに入り、グループの中は矢印キーで移ります。グループの中の項目をひとつずつ Tab で渡らせると、ページの奥へ進むのに何度も押すことになるためです。

## フォーカスの戻り先

ダイアログやメニューを閉じたら、開いたボタンにフォーカスを戻します。閉じたあとにフォーカスが行方不明になると、キーボードの利用者は現在地を見失います。

## フォーカスの見え方

フォーカスリングは `:focus-visible` のときにブランドカラーで 2px 出します。マウスで押したときには出しません。フォーカスリングを消すときは、必ず別の見え方で代えます。

## 確かめ方

コンポーネントごとのキーボード操作は、各コンポーネントページの「仕様」に表で載せています。操作を自動で確かめるテストは、作業台（`bun run workbench`）でストーリーを開くと再生され、結果は下のパネルの「Interactions」で見られます。
